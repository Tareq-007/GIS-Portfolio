# Project 01 – Live Air Traffic Dashboard

## Overview

This project visualizes live aircraft positions using OpenSky Network data on an interactive map.

## Objective

Develop a real-time aviation dashboard capable of displaying aircraft locations and movement.

## Features

- Live aircraft positions
- Flight information
- Interactive visualization
- Spatial filtering

## Tools

- Python
- OpenSky API
- GIS Visualization

## Outputs

- Live dashboard
- Interactive map
