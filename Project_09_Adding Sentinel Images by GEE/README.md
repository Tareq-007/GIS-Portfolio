\# Sentinel-2 Image Processing using Google Earth Engine



\## Overview

This project demonstrates satellite image processing using Sentinel-2 Harmonized imagery in Google Earth Engine.



Images are filtered by the study area (ROI), cloud cover, and acquisition date before generating a cloud-free median composite. Different band combinations are applied to visualize land cover characteristics for natural color viewing, vegetation analysis, and agricultural assessment.



\## Workflow

\- Import Sentinel-2 Harmonized imagery

\- Filter images by Region of Interest (ROI)

\- Filter by cloud cover (<1%)

\- Filter by acquisition date

\- Generate a median composite

\- Clip the image to the study area

\- Visualize using different band combinations



\## Visualizations

\- \*\*True Color Composite\*\* – Natural representation of the Earth's surface.

\- \*\*False Color Composite\*\* – Highlights healthy vegetation and water bodies.

\- \*\*Agriculture Composite\*\* – Enhances crop conditions, vegetation, and soil moisture differences.



\## Tools

\- Google Earth Engine

\- JavaScript

\- Sentinel-2 Harmonized



\## Outputs

\- True Color Map

\- False Color Map

\- Agriculture Composite Map
