# GIS & Remote Sensing Portfolio

Welcome to my GIS and Remote Sensing project portfolio.

This repository showcases practical geospatial analysis projects completed using Google Earth Engine, QGIS, and satellite imagery. The projects focus on solving real-world environmental, urban planning, aviation, and disaster management problems through spatial analysis.

## Skills Demonstrated

- Google Earth Engine (GEE)
- Remote Sensing
- GIS Analysis
- Land Use/Land Cover Classification
- Environmental Monitoring
- Change Detection
- Spatial Analysis
- UAV & Aviation Geospatial Applications
- Satellite Image Processing
- Map Design & Visualization

## Projects

### Project 01 – Live Air Traffic Dashboard
Real-time aircraft visualization using OpenSky Network data.

### Project 02 – Carbon and Soil Mapping
Assessment of vegetation health, carbon storage potential, and soil characteristics using satellite imagery.

### Project 03 – Land Use / Land Cover Classification
Classification of urban, vegetation, water, and bare land using machine learning techniques.

### Project 04 – Spatial Audit: Urban Safety Buffer Analysis
Buffer analysis around public infrastructure to evaluate accessibility and urban planning.

### Project 05 – Land Surface Temperature Mapping
Thermal analysis using Landsat imagery to identify urban heat islands.

### Project 06 – Vulnerability Mapping
Spatial analysis for identifying vulnerable schools and critical infrastructure.

### Project 07 – Earthquake Risk Assessment
Hazard visualization and spatial analysis for earthquake-prone regions.
