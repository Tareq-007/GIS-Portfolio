# 🌍 Land Use & Land Cover (LULC) Change Analysis – Chattogram, Bangladesh

## Project Overview

This project analyzes how land use and land cover have changed across Chattogram between **2016**, **2020**, and **2024** using satellite imagery and cloud-based geospatial analysis.

The study identifies changes in urban development, vegetation, water bodies, and other land cover types to support environmental monitoring and sustainable urban planning.

---

## Project Objectives

- Monitor land cover changes over time.
- Detect urban expansion.
- Evaluate vegetation loss and gain.
- Support environmental and infrastructure planning.
- Produce GIS-ready maps and statistics.

---

## Study Area

**Location:** Chattogram, Bangladesh

**Study Period:**
- 2016
- 2020
- 2024

---

## Workflow

1. Acquire satellite imagery.
2. Preprocess and filter cloud-free images.
3. Generate annual composite images.
4. Classify land cover.
5. Compare yearly classifications.
6. Visualize land cover changes.
7. Export final maps and statistics.
